# 总拥有成本 TCO

TCO（Total Cost of Ownership）把采购决策从“采购价格”扩展为“获取、使用、维护、风险和处置的全生命周期成本”。

## 成本构成

- 购买价格、税费、运输、保险、清关；
- 寻源、谈判、订单、验收、付款等交易成本；
- 安装、培训、集成、切换成本；
- 运营、能源、耗材、维护与维修；
- 缺陷、返工、停线、客户索赔；
- 库存持有、资金占用和过时风险；
- 供应中断、合规、安全与环境成本；
- 残值、回收和处置。

## 比较方法

### 单期成本

适合采购频率低、使用期短、差异容易量化的项目。

### 全生命周期

将不同时间点成本折现：

```text
NPV = Σ [成本_t / (1 + r)^t]
```

其中 `r` 为折现率，`t` 为时间期。除了 NPV，还可计算回收期、内部收益率和年化成本。

## 采购中的应用

1. 明确比较边界：哪些成本和风险纳入；
2. 建立基准：现有方案或最低合格方案；
3. 统一单位、时间和数量；
4. 量化可量化项，列出不可量化项；
5. 做敏感性分析：需求、价格、汇率、故障率变化；
6. 记录最终选择与例外理由。

## 常见误区

- 只比较首次报价；
- 把供应商承担的库存成本误认为企业成本消失；
- 忽略质量、停机和客户流失；
- 使用过于复杂的模型但没有可靠数据；
- 用 TCO 为高价方案背书，却不验证收益。
