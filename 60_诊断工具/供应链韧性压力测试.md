# 供应链韧性压力测试

## 场景库

选择与业务相关的情景：

1. 关键供应商停产 2-8 周；
2. 关键运输路线中断或运费翻倍；
3. 区域需求突然增长 30%；
4. 需求下降 30% 且库存积压；
5. 汇率或关税突变；
6. 质量事故导致召回；
7. 网络攻击或系统停机；
8. 能源、劳动力或水资源约束。

## 测试表

| 项目 | 问题 |
|---|---|
| 暴露 | 多少收入、客户和关键物料受影响？ |
| 可替代 | 是否有认证的替代来源、路线、产能或材料？ |
| 时间 | 识别、决策、切换和恢复分别需要多久？ |
| 库存 | 现有库存能支撑多久，是否会被单点占用？ |
| 现金 | 中断期间的现金流和合同责任是多少？ |
| 信息 | 多久能知道事件，谁有权启动响应？ |
| 客户 | 哪些客户和承诺优先？ |
| 合规 | 替代方案是否满足法规、质量和 ESG？ |

## 度量

- 受影响收入；
- 中断持续时间；
- 恢复时间；
- 客户失约数；
- 额外成本；
- 替代来源切换周期；
- 预案启动时间；
- 学习后的能力提升。

## 结果分级

- 绿：可吸收，现有控制足够；
- 黄：需临时调整和跨部门决策；
- 红：现有能力无法承受，需要结构性改变；
- 黑：存在系统性连锁风险，需最高层治理。
