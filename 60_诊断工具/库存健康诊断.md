# 库存健康诊断

库存健康不能只看周转率。要同时看服务、结构、准确性和现金。

## 六个指标

1. **库存周转率** = 销售成本 / 平均库存
2. **库存天数** = 365 / 周转率
3. **缺货率** = 缺货需求 / 总需求
4. **服务水平** = 按承诺满足的订单比例
5. **呆滞库存占比** = 超期或低动销库存 / 总库存
6. **库存准确率** = 账实一致数量 / 抽查数量

## 分层分析

- 原材料、在制品、成品、渠道库存；
- ABC 金额分类；
- XYZ 需求稳定性；
- 通用/专用；
- 生命周期阶段；
- 供应商与地点的独有风险。

## 高库存与缺货并存的原因

- 库存结构错误：积压非畅销品，缺关键品；
- 计划颗粒度错误：总量够，SKU/地点不够；
- 需求波动未进入安全库存；
- 提前期变化未更新；
- 订单锁定或项目专用库存未释放；
- 渠道压货扭曲需求；
- 数据不准确；
- 过度追求局部周转。

## 诊断步骤

1. 按物料/地点/SKU 拉取库存和需求；
2. 标注在途、锁定、质检、寄售和渠道库存；
3. 计算缺货与积压的重叠；
4. 分析主要成本与服务水平权衡；
5. 按品类制定补货和服务策略；
6. 设置库存健康仪表盘和复核节奏。
