# 供应链金融

供应链金融利用核心企业与上下游的真实交易关系，把主体信用、交易信用和资产信用结合，为供应链提供融资、结算和风险缓释。

## 主要模式

| 模式 | 融资基础 | 主要风险 |
|---|---|---|
| 应收账款融资/保理 | 已确认应收与买方信用 | 贸易真实性、回款控制、重复融资 |
| 反向保理 | 核心企业确认应付 | 核心企业信用集中 |
| 订单融资 | 订单与履约能力 | 订单取消、交付失败 |
| 预付款融资 | 采购合同与货权控制 | 供应商挪用、货物质量 |
| 存货融资/仓单质押 | 可控制存货 | 价格波动、重复质押、监管失效 |
| 动态折扣 | 提前付款换取折扣 | 折扣与资金成本的比较 |

## 价值判断

供应链金融应同时改善：

- 上下游资金可获得性；
- 核心企业付款与供应稳定；
- 融资成本；
- 现金流周期；
- 风险透明度。

如果只是把融资成本或账期压力转嫁给弱势供应商，长期会损害供应韧性和价格。

## 风险控制

- 真实交易与发票核验；
- 核心企业确权；
- 资金闭环与回款控制；
- 货权与仓储监管；
- 信用与集中度监测；
- 防止重复融资和虚假贸易；
- 法律与合规审查。
