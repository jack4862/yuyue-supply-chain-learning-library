# 供应链风险治理

## 治理四件套

1. **风险偏好**：企业愿意承担哪些风险、到什么程度；
2. **责任体系**：谁识别、谁评估、谁批准、谁执行；
3. **流程与规则**：风险登记、评估、升级、应对和复盘；
4. **数据与预警**：事件、指标、外部信号和供应商风险。

## 风险登记最小字段

- 风险事件；
- 来源与触发条件；
- 发生概率；
- 影响对象与严重程度；
- 现有控制；
- 预警指标；
- 应对策略；
- 责任人；
- 最后复核日期。

## 风险矩阵

用概率 × 影响排序，但不要只看数字：

- 低概率高影响风险往往需要预案而不是日常优化；
- 高概率低影响风险可以通过标准化和自动化处理；
- 多个风险可能相关并共同造成系统性中断；
- 风险等级会随暴露、控制和环境变化。

## 业务连续性

- 业务影响分析；
- 关键流程与最低服务目标；
- 备用供应商、产能、库存、路线和人员；
- 恢复时间目标与恢复点目标；
- 演练与更新。

## 风险响应

| 策略 | 适用条件 | 注意点 |
|---|---|---|
| 降低 | 可控制系统或暴露 | 不要把控制文件当实际控制 |
| 转移 | 合同、保险可覆盖 | 转移不等于消除 |
| 分担 | 伙伴有互补能力 | 需要透明和治理 |
| 接受 | 在风险偏好内 | 明确监控与阈值 |
| 规避 | 风险超出承受能力 | 评估业务损失 |
