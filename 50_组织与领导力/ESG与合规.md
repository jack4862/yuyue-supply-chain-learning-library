# ESG 与合规

## 三个维度

- **E 环境**：碳排、能源、水、废弃物、污染、循环利用；
- **S 社会**：劳工、健康安全、人权、公平、社区；
- **G 治理**：反腐败、合规、数据、董事会责任、透明披露。

## 进入供应链管理的方式

| 环节 | 具体动作 |
|---|---|
| 战略 | 明确优先议题、目标和风险边界 |
| 设计 | 选择材料、产品、网络与运输方式 |
| 采购 | 准入、合同、行为准则、审核 |
| 生产 | 能源、排放、安全、质量管理 |
| 交付 | 包装、运输、碳排、服务 |
| 回收 | 退货、再利用、再制造、处置 |
| 绩效 | 指标、审计、披露和纠正 |

## 合规控制

- 法规识别与更新；
- 供应商筛查；
- 授权与职责分离；
- 合同条款；
- 记录和审计轨迹；
- 异常与举报；
- 纠正和处罚；
- 高层责任。

## 常见失败

- 目标宏大但没有基线；
- 只审一级供应商；
- 供应商自报数据无验证；
- 采购仍只按最低价格决策；
- 合规文件存在但流程未执行；
- 将范围 1/2/3 排放混为一谈。
