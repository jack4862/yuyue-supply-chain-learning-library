# 沟通与协同

## 协同的三个层次

1. **信息协同**：共享需求、库存、产能和风险；
2. **流程协同**：跨部门或跨企业共同计划、执行和异常处理；
3. **决策协同**：就取舍、资源分配和风险承担形成共同决定。

只共享信息，不改变流程和决策，通常只是“看得更多，做得照旧”。

## 一个有效会议的最小结构

- 输入是否提前统一；
- 需要做什么决策；
- 谁有决策权；
- 备选方案和取舍；
- 决策与责任人；
- 截止时间和验证指标；
- 未决事项升级路径。

会议如果没有决策问题，就不必以会议形式召开。

## 跨部门冲突处理

1. 把立场翻译成利益；
2. 用数据确认事实；
3. 明确约束与授权；
4. 寻找扩大总价值的方案；
5. 若不能双赢，由更高层做透明取舍；
6. 记录决定和后果责任。

## 避免协同失真

- 指标不一致；
- 数据统计口径不同；
- 只汇报结果，不暴露风险；
- 例外无升级机制；
- 会议多但没有授权；
- 共享信息被用于追责而非解决问题。
