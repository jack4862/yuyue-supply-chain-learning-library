# 案例分析法

## 六步结构

1. **事实**：只写可验证数据和事件；
2. **问题**：把症状翻译成管理问题；
3. **机制**：解释因果关系；
4. **方案**：至少两个备选方案；
5. **取舍**：比较收益、成本、风险和可执行性；
6. **验证**：指标、时间和退出条件。

## 避免三种错误

- 先有答案再找证据；
- 只列工具名称，不说明输入与输出；
- 把“加强管理”“提升协同”当行动。

## 一份完整案例答案

```text
结论：最重要的约束是……
证据：……
原因：……
方案 A：……
方案 B：……
推荐：……
指标：……
风险：……
下一步：……
```
