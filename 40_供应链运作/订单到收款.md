# 订单到收款

O2C（Order-to-Cash）把客户订单转化为收入与现金，是供应链和财务的交汇流程。

## 端到端步骤

```mermaid
flowchart LR
    A[客户下单] --> B[信用与订单确认]
    B --> C[供应能力承诺]
    C --> D[采购/生产/库存分配]
    D --> E[检验与发运]
    E --> F[交付与验收]
    F --> G[开票与对账]
    G --> H[收款]
    H --> I[异常与争议处理]
```

## 数据一致性

以下对象必须可追溯：

- 客户与合同；
- 销售订单；
- 库存/生产订单/采购订单；
- 发运与交付；
- 发票；
- 收款。

在系统中常见问题是“货物已发但订单未关闭”“发票数量与验收不一致”“客户拒收但库存未回冲”，这些会同时影响交付和财务。

## 关键指标

- 订单周期；
- 完美订单满足率；
- 按时交付率；
- 变更/取消率；
- 开票周期；
- DSO；
- 争议金额和解决周期；
- 现金回收率。
