# 学习地图

供应链学习最容易犯的错误，是先记术语再解决问题。更有效的顺序是：**先建立端到端地图，再学习各环节工具，最后用诊断问题把工具放回业务现场。**

## 第一层：建立共同语言

先读：

1. [[10_框架/端到端供应链]]
2. [[10_框架/SCOP模型]]
3. [[10_框架/SCOR模型]]
4. [[10_框架/供应链三重目标]]
5. [[10_框架/战略匹配]]

完成后，你应能用一条链说清：客户需求如何变成计划，计划如何驱动采购和生产，库存和物流如何支撑交付，现金如何回收。

## 第二层：掌握采购主线

阅读顺序：

[[20_采购管理/第01章-采购需求]] → [[20_采购管理/第02章-品类管理]] → [[20_采购管理/第03章-寻源管理]] → [[20_采购管理/第07章-采购谈判]] → [[20_采购管理/第08章-合同管理]] → [[20_采购管理/第09章-采购与供应商绩效]]

三条关键判断线：

- **买什么**：需求与规格是否清楚？
- **向谁买、怎么买**：品类策略、供应市场与竞争方式是否匹配？
- **如何持续创造价值**：合同、绩效、发展、风险和退出是否闭环？

## 第三层：掌握规划主线

阅读顺序：

[[30_供应链规划/第01章-供应链环境与战略]] → [[30_供应链规划/第02章-供应链设计]] → [[30_供应链规划/第03章-供应链集成与优化]] → [[30_供应链规划/第04章-供应链成本管理]] → [[30_供应链规划/第05章-供应链财务分析与金融]] → [[30_供应链规划/第06章-数字化供应链]]

规划主线回答四个问题：

- 网络应该放在哪里？
- 需求与供应如何形成一套可执行计划？
- 成本与资本如何平衡？
- 技术如何增强而不是替代管理？

## 第四层：掌握运作主线

阅读顺序：

[[40_供应链运作/第02章-客户需求与交付]] → [[40_供应链运作/第03章-库存管理基础]] → [[40_供应链运作/第04章-物流管理]] → [[40_供应链运作/第05章-生产运作]] → [[40_供应链运作/第08章-质量管理]]

运作主线关注的是“承诺是否兑现”：

- 订单承诺是否有供应能力依据？
- 库存是否在正确的地点、以正确的形态存在？
- 物流与生产是否按同一节奏运行？
- 质量问题是预防不足、过程失控还是检验失效？

## 第五层：组织领导与风险

阅读顺序：

[[50_组织与领导力/第02章-战略与目标]] → [[50_组织与领导力/第03章-组织规划与重组]] → [[50_组织与领导力/第05章-伙伴关系管理]] → [[50_组织与领导力/第06章-沟通与协同]] → [[50_组织与领导力/第07章-组织绩效管理]] → [[50_组织与领导力/第09章-供应链风险管理]]

供应链问题很少只属于一个部门。领导力主线帮助你回答：

- 谁对端到端结果负责？
- 目标如何分解而不造成局部优化？
- 如何让供应商与客户参与协同？
- 风险由谁识别、谁决策、谁承担后果？

## 第六层：用问题检验理解

进入 [[60_诊断工具/端到端诊断问题库]]，选择一个真实场景：

- 采购降本但总成本上升；
- 交付率下降但库存也上升；
- S&OP 每月开会却没有决策；
- 单一供应商成本最低但中断风险高；
- 数字化系统上线后流程反而更慢。

每次诊断都应输出：问题定义、证据、根因假设、方案选择、指标验证和复盘。
