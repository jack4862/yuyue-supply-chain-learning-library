# S&OP 会议模板

## 会前输入

- 上月实际销售、订单、库存、交付和财务；
- 需求预测与假设；
- 产能、物料、供应商和物流约束；
- 供应缺口、风险和备选方案；
- 需要高层决策的议题。

## 议程

### 1. 绩效回顾

- 关键指标偏差；
- 主要原因；
- 已采取的纠正措施；
- 未解决事项。

### 2. 需求计划

- 基准、乐观、悲观情景；
- 关键假设；
- 重点客户/产品；
- 风险与机会。

### 3. 供应计划

- 产能和物料缺口；
- 供应商与物流约束；
- 恢复方案；
- 成本与交付影响。

### 4. 供需平衡

- 缺口/过剩；
- 备选方案；
- 客户优先级；
- 财务影响。

### 5. 决策

| 议题 | 方案 A | 方案 B | 推荐 | 决策 | 责任人 | 截止 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

## 会后检查

- 是否只有一个共识计划？
- 是否有明确决策和授权？
- 变更是否同步到采购、生产、物流和财务？
- 下次会议验证哪些结果？
