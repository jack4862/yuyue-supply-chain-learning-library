## 扫描与 OCR 状态

四份 PDF 均为扫描版，没有可直接提取的文本层。当前证据链为：

1. 用 Poppler 按 120 DPI 渲染页面；
2. 用 Windows OCR 进行中文识别；
3. 保留逐页 JSON 原始结果；
4. 生成按页分隔、经过轻量空白规整的 Markdown 全文底稿，供 Obsidian 全局搜索。

OCR 共覆盖 1,263 个 PDF 页面，原始识别约 181.5 万字符；去掉中文之间的识别空白后，搜索底稿约 99.1 万字符。机器识别可能存在错字、串行、表格顺序错乱和页眉页脚误识别；涉及定义、数字、法条或引语时，必须对照 PDF 原页核验，不能把 OCR 底稿本身当作原文。
